Samruddhi Homestay – Managed Booking Website

June 2026 - July 2026

Project Overview

Developed a modern, fully managed website for Samruddhi Homestay in Mangaluru. The platform showcases the homestay and lets guests check availability and book directly through WhatsApp, giving the owners a clean, professional online presence.

I handled the complete build end-to-end - frontend, backend, and hosting - so the owners receive a polished, maintainable site without managing any infrastructure themselves.

Key Features & Technologies

  • Next.js: Built a fast, SEO-friendly modern web app for the homestay.
  • Firebase: Powered the backend for storing bookings and availability data in real time.
  • WhatsApp Booking: Integrated booking flow that directs guest requests straight to WhatsApp.
  • Tailwind CSS & shadcn/ui: Optimized the frontend with a modern, responsive, and accessible UI.
  • Fully Managed: Complete setup, deployment, and maintenance handled as the sole developer.
